# CISD Journal — نظام الانضباط والأداء للتداول

تطبيق Windows محلي بالكامل مبني على Electron. يراقب إشارات CISD القادمة من ملف CSV في JForex،
ويقيس الفجوة بين **الإشارة** و**قرار التنفيذ**.

> التطبيق لا يفتح ولا يعدّل ولا يغلق أي صفقة. القراءة فقط.

## الميزات الحالية

### الحسابات والمخاطرة
- حسابات متعددة ومعزولة تماماً (FundingPips / FundedNext / Practice).
- رأس المال، هدف الربح، حد الخسارة اليومي، وأقصى تراجع لكل حساب.
- حساب أقصى تراجع من **أعلى رصيد وصله الحساب** (high-water mark) كما تفعل شركات التمويل.
- حد الخسارة اليومي يُحسب على **اليوم التداولي بتوقيت نيويورك** وليس بتوقيت UTC.
- تنبيهات: اقتراب من الحد، اختراق الحد، سلسلة خسائر متتالية.

### الإشارات والانضباط
- مراقبة ملف `HigherTF_Signals.csv` تلقائياً كل ثانيتين.
- لكل إشارة: دخلت / لم أدخل + سبب عدم الدخول.
- درجة انضباط، نسبة تغطية القرارات، وأسباب التردد الأكثر تكراراً.

### اليوميات
- تسجيل صفقة يدوية أو مرتبطة بإشارة.
- **صور الشارت قبل وبعد** الدخول.
- الوسوم والملاحظات، وتصدير الصفقات إلى CSV.

### الاستيراد
- FundedNext CSV (استيراد يدوي أو مراقبة مجلد) مع فصل المراكز المفتوحة ومنع تكرار الـTicket.
- تقارير MT5 بصيغة HTML أو CSV.
- مزامنة FundingPips Shared Dashboard.
- مزامنة MT5 عبر Investor Pass (قراءة فقط) من خلال جسر مستقل.

### الباكتيست والتحليلات
- جلسات Backtest Replay مع فلاتر (التاريخ، الجلسة، الرمز، الفريم) ومراجعة كل إشارة.
- Win Rate، Net R، Profit Factor، Expectancy، منحنى الإكويتي، التراجع، الهيت ماب.
- تفصيل حسب المصدر والجلسة والرمز والاتجاه والوسم والشهر.

### أخرى
- واجهة ثنائية اللغة (عربي RTL / إنجليزي LTR) بالكامل.
- نسخ احتياطي واستعادة محلية، وتصفير حساب محدد.
- كل البيانات تُحفظ محلياً فقط.

## التطوير

```bash
npm ci
npm test          # 20 مجموعة اختبار
npm run dist:win  # بناء مثبّت Windows
```

## بناء EXE من GitHub

1. ارفع المشروع إلى Repository خاص.
2. افتح تبويب **Actions** واختر `Build CISD Journal EXE`.
3. اضغط **Run workflow**.
4. نزّل Artifact باسم `CISD-Journal-Windows-EXE`.

## الخصوصية

- لا ترفع مفاتيح API أو بيانات دخول أو تقارير حسابات إلى المستودع.
- مفاتيح الأخبار وكلمات Investor Pass تُحفظ مشفّرة محلياً عبر `safeStorage`.
- ملف `.gitignore` يمنع رفع بيانات اليوميات والنسخ الاحتياطية.
