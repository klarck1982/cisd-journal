# CISD Journal v1.0.0 — Release Notes Draft

## Overview
CISD Journal is a local Windows Trading Performance & Discipline OS built around CISD signals, manual execution, prop-firm account tracking, Backtest Replay, and practical trading reviews.

## Dashboard
- Multi-account FundingPips / FundedNext challenges.
- Account Health, Capital, Balance, Projected Equity, Challenge Progress.
- Risk Status: Daily P&L, Open P&L, Daily Loss, Max Drawdown, loss streak warnings.
- Data Sources Status.
- Upcoming High-Impact News widget.

## Trading Journal
- Manual trades with Entry, SL, TP, R, tags, notes, and before/after screenshots.
- Signal Link between a manual trade and a CISD signal.
- Search, source filter, trade detail view, and CSV export.

## Data Imports
- JForex HigherTF_Signals.csv watcher.
- FundedNext CSV importer and watched reports folder.
- Open positions separated from closed trades.
- Generic MT5 Detailed Report HTML/CSV importer.
- Duplicate Ticket/Deal protection.

## Backtest
- Backtest Capture Mode.
- Replay decisions and Win/Loss/BE/R recording.
- Session comparison, archive, reset, and progress.

## Analytics
- Win Rate, Net R, Profit Factor, Expectancy.
- Equity Curve, Max/Current Drawdown.
- Calendar, Heatmap, Monthly Performance.
- Instrument, Long/Short, Session, Tags, Source, and Period filters.

## Discipline
- Daily Checklist, Notes, Weekly Review, XP, Streak, Achievements.
- Missed opportunity reasons.

## Safety & Support
- Local encrypted news API key storage.
- Atomic data saving, corrupt-data recovery, backup/restore, account reset confirmation.
- In-app Help Center, first-launch onboarding, full offline HTML user guide.
- Windows notification support.

## Installer
- NSIS Windows Installer.
- Desktop shortcut, Start Menu shortcut, custom application icon, uninstall support.

## Final validation still required
- Windows runtime and installer test.
- Real MT5 HTML report validation.
- FMP Free API live test.
- FundingPips Shared Dashboard policy confirmation.
