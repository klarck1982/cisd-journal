CISD Journal

دليل المستخدم — Trading Performance & Discipline OS

الإصدار 1.0.0

1. ما هو CISD Journal؟

تطبيق Windows محلي يساعدك على متابعة الحسابات والصفقات وإشارات CISD والـBacktest والانضباط والمخاطرة في مكان واحد. التطبيق لا يفتح أو يعدل أو يغلق أي صفقة.

2. البداية السريعة

  1. أنشئ حساباً من الشريط الجانبي.
  2. أدخل Initial Capital وProfit Target وDaily Loss Limit وMax Drawdown.
  3. اختر ملف HigherTF_Signals.csv من JForex.
  4. حدد مجلد FundedNext Reports أو استورد تقرير MT5.
  5. أكمل Checklist اليوم قبل التداول.

3. Dashboard

Account Health

يعرض Capital وBalance وProjected Equity وDaily Loss وMax Drawdown وProfit Target.

Focus Mode

يعرض أهم مهمة حالية أو إشارة CISD تحتاج قراراً. الهدف هو تقليل التشتيت وليس دفعك لدخول صفقات.

Risk Status

يعرض Today Closed P&L وOpen P&L والمراكز المفتوحة والتنبيهات.
مثال: إذا اقتربت من حد الخسارة اليومي تظهر رسالة ATTENTION.

4. الحسابات والـChallenges

كل حساب مستقل: FundingPips وFundedNext أو Practice. لا تختلط صفقات أو Notes أو Backtests أو التحليلات بين الحسابات.

5. إشارات CISD

الإشارات تصل من ملف JForex CSV. لكل إشارة تختار: وضعت أمراً أو لم أدخل أو خارج خطتي.
مثال: ظهر +CISD على XAUUSD، فتسجل قرارك مع سبب عدم الدخول إن لم تأخذ الفرصة.

6. الصفقات اليدوية

استخدم إضافة صفقة يدوية لصفقة دخلتها بقرارك. أضف الرمز والاتجاه وEntry وSL وTP وR وTags وNote وصور قبل/بعد الدخول. يمكن ربطها بإشارة CISD اختيارياً.

7. FundedNext وMT5 Import

FundedNext CSV

استورد CSV أو حدد Reports Folder. التطبيق يمنع تكرار Ticket ID ويحسب Net P&L من Profit + Commission + Swap.

MT5 Detailed Report

استورد HTML أو CSV من Account History. لا يحتاج EA ولا API ولا بيانات دخول.

8. Backtest Replay

اضغط Start New Backtest قبل تشغيل JForex Backtest. يلتقط التطبيق إشارات CSV ضمن الجلسة. بعد النهاية سجل Win أو Loss أو BE وR. يمكن مقارنة الجلسات وأرشفتها أو تصفيرها.

9. Analytics

تشمل Win Rate وNet R وProfit Factor وExpectancy وEquity Curve وDrawdown وCalendar وHeatmap وInstrument Analysis وLong/Short وSession وTags وMonthly Performance.

10. Upcoming News

يعرض أخبار High Impact مع Countdown. اختر FMP Free أو Trading Economics من الإعدادات وأدخل API Key. الأخبار سياق للمعلومة وليست توصية تداول.

11. Backup وReset

استخدم Export Backup قبل أي Reset كبير. Restore Backup ينشئ نسخة أمان من البيانات الحالية قبل الاستعادة.
Reset Current Account يمسح بيانات الحساب المحدد فقط بعد كتابة RESET. لا يمكن التراجع عنه بدون Backup.

12. Data Sources Status

يوضح آخر تحديث لـJForex وFundedNext وMT5 وFundingPips Shared Dashboard، حتى تعرف إن كان أي مصدر يحتاج إعداداً.

13. الخصوصية

البيانات تحفظ محلياً. لا يتم رفع API Keys أو حسابات أو صفقات إلى GitHub. FundingPips Shared URL يحفظ محلياً فقط.
