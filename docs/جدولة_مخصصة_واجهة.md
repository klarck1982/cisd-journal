## التشخيص السريع لحالتك

بما أنك تستخدم **أكثر من حساب وأكثر من مصدر**، أكثر صفحتين تهمك هي:
1. **Overview** - لأنك تبدل بين حسابات كثيرة وتريد أن ترى بسرعة أي حساب في خطر
2. **Data** - لأنك تحتاج أن تعرف: هل مجلد FundedNext يراقب؟ هل جسر MT5 يعمل؟ هل إشارات JForex تصل؟

الواجهة الحالية **وصلت 75% من المستوى المطلوب** حسب `GAP_TO_MOCKUP_PASS.md`:
- ✅ نظام ألوان موحد (تم إصلاح 218 لون يدوي)
- ✅ خط عربي IBM Plex مضمن
- ✅ أرقام تصطف عمودياً
- ✅ حلقة تركيز
- ❌ البطاقات كلها تبدو متشابهة (KPI = تحذير = ملاحظة)
- ❌ منحنى الإكويتي لا يوجد به محور ولا تفاعل كامل
- ❌ لا يوجد سحب وإفلات
- ❌ لا بحث عالمي

## الجدولة المخصصة - 4 أسابيع (تركيز واجهة)

### الأسبوع 1: لوحة القيادة القابلة للترتيب + حسابات كثيرة ⭐ (أنت طلبت هذا)

**الهدف:** تجعل Overview مفيدة مع 3-5 حسابات

| # | المهمة | ماذا سترى؟ |
|---|---|---|
| 1.1 | سحب وإفلات البطاقات في Overview | تمسك بطاقة "حالة المخاطرة" وتسحبها للأعلى، تحفظ تلقائياً |
| 1.2 | تحسين Account Rail مع حسابات كثيرة | بحث سريع فوق قائمة الحسابات + تصنيف حسب Firm + مؤشر خطر بجانب كل حساب (أخضر/أصفر/أحمر) |
| 1.3 | بطاقات Variants ذكية | بطاقة الخطر تبدو مختلفة فوراً عن بطاقة الأخبار (لون/حد/أيقونة) |
| 1.4 | Hero Section أقوى | رقم واحد كبير: "أنت على بعد -X من حد الخسارة" + زر إجراء واضح |

**اختبارات:** `qa/design-system-tests.js` + يدوي على Windows

### الأسبوع 2: صفحة البيانات + التحليلات لـ "الكل"

**الهدف:** بما أنك تستخدم كل المصادر، تحتاج أن ترى صحتها في مكان واحد

| # | المهمة | ماذا سترى؟ |
|---|---|---|
| 2.1 | صفحة Data جديدة - Diagnostics Dashboard | 4 بطاقات: JForex CSV (آخر تحديث منذ X ثانية + عدد الإشارات اليوم) / FundedNext Folder (يراقب/متوقف + آخر ملف) / MT5 Bridge (متصل/غير متصل + آخر مزامنة) / النسخ الاحتياطي (آخر نسخة) |
| 2.2 | تحسين Analytics لـ Multi-Account | فلتر "قارن حسابين" + مجموع كل الحسابات |
| 2.3 | كثافة أعلى في Journal | جدول يعرض 20 صفقة بدل 8، مع تجميد رأس الجدول، وتلوين R إيجابي/سلبي أوضح |
| 2.4 | بحث عالمي Ctrl+K | تضغط Ctrl+K → تكتب "ذهب" أو "خوف" يجد صفقات + إشارات + ملاحظات |

### الأسبوع 3: الرسوم والجمال النهائي

| # | المهمة | ماذا سترى؟ |
|---|---|---|
| 3.1 | منحنى إكويتي تفاعلي كامل | تمرر الفأرة ترى: التاريخ + الربح + الرصيد التراكمي + خط متقطع + نقطة على المنحنى، مع محور أرقام على الجانب |
| 3.2 | تقويم P&L محسن | ألوان أوضح، مجموع أسبوعي، أفضل/أسوأ يوم محدد بنجمة |
| 3.3 | تحسين Backtest page | Banner يوضح: "جلسة 15 يناير - 42 إشارة - WinRate 58%" + شريط تقدم المراجعة |
| 3.4 | حالات فارغة موجهة أفضل | بدل "لا بيانات"، ترى: "لم تستورد FundedNext بعد" + زر "اختر مجلد" يعمل مباشرة |

### الأسبوع 4: حفظ البيانات + الأمان (مختصر)

**لأنك تستخدم "الكل"، حفظ البيانات يصبح حرجاً**

| # | المهمة | ماذا سترى؟ |
|---|---|---|
| 4.1 | نسخ احتياطي Versioned | في الإعدادات ترى: 5 نسخ (اليوم، أمس...) + حجم كل نسخة + استعادة بضغطة |
| 4.2 | تصدير CSV مجمع | تختار تصدير كل حساباتك معاً في ملف واحد مع عمود AccountName |
| 4.3 | ترقية Electron 37→43 | لا شيء مرئي، لكن إغلاق 17 ثغرة + بناء أسرع |
| 4.4 | SHA256 checksums | ملف تحقق مع كل إصدار |

## لماذا هذا الترتيب؟

```
أسبوع 1-2: ما يزعجك يومياً (واجهة + حسابات كثيرة) → قيمة فورية
أسبوع 3: الجمال (رسوم + تقويم) → يجعل التطبيق يبدو مدفوعاً
أسبوع 4: الأمان + حفظ البيانات → يحمي عملك على المدى الطويل
```

لو بدأنا بالأمان أولاً (التوصية الفنية)، ستقضي أسبوعاً بلا أي فرق مرئي، وهذا محبط. 
بما أنك تستخدم كل المصادر، البدء بالواجهة يعطيك دفعة حماس.
