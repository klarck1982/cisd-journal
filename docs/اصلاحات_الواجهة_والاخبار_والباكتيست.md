## 3️⃣ إصلاح تداخل البطاقات والإعدادات المقطوعة

### السبب الجذري (وجدنا 3 أسباب):
1. `will-change: transform` على كل البطاقات يسبب طبقات GPU متداخلة عند الانتقال (bug في Electron 37)
2. أنيميشن `fadeUp` كان يستخدم `translateY(4px)` مما يجعل الصفحتين تتداخلان للحظة أثناء الانتقال
3. `content::before` التوهج الأزرق كان فوق المحتوى (z-index خاطئ)
4. `padding-bottom` كان 22px فقط، فالإعدادات في الأسفل (حسابات مؤرشفة) كانت مقطوعة

### ما تم إصلاحه في `renderer/style.css`:

```css
/* قبل */
.page { animation: fadeUp var(--motion); }
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(4px); }
  to { opacity: 1; transform: translateY(0); }
}
.breakdown-card, .metric-card { will-change: transform; }
.content { padding: 22px; }

/* بعد */
.page { animation: fadeUp 120ms ease-out; isolation: isolate; }
@keyframes fadeUp {
  from { opacity: 0; }
  to { opacity: 1; }
}
.breakdown-card, .metric-card { will-change: auto; } /* إلغاء الطبقات */
.content { padding: 22px 22px 80px 22px; z-index: 0; }
.content::before { z-index: -1; } /* خلف المحتوى */

.page[data-page="settings"] { padding-bottom: 120px; }
#archivedAccountsPanel { margin-bottom: 40px; }

.grid, .panel { min-width: 0; overflow: hidden; } /* منع التداخل */
```

### النتيجة:
- لا تداخل عند الانتقال بين الصفحات
- الإعدادات تظهر كاملة حتى الأسفل مع مسافة 120px إضافية
- البطاقات لا تتداخل ولا تومض
